## CounterFact (user-specified)

Source: [azhx/counterfact](https://huggingface.co/datasets/azhx/counterfact), pinned revision `c01c413f856ee38f5c080c9fc5e87aff478e2ff9`; original benchmark from ROME. Local `counterfact/*.parquet`. Train19,728 and test2,191 records (21,919 total),12,387,190 compressed bytes. Seven fields: `case_id`, `pararel_idx`, structured `requested_rewrite` (prompt,subject,relation_id,target_true,target_new), and lists of paraphrase, neighborhood, attribute and generation prompts. No top-level nulls; all rewrites nonempty. Hashes and download URLs: `validation.json`; actual three-record sample: `counterfact_sample.json`.

Use to measure factual-answer spillover under the arithmetic edit and optionally sanity-check existing editors. Preserve this mirror's splits; do not assume they match every paper's evaluation partition. It does not contain arithmetic edits and cannot replace the custom suite. The hosted card does not specify a data license; provenance is known but redistribution terms remain unresolved. A code repository's license is not automatically a dataset license.

## GSM8K test

Source: [official grade-school-math repository](https://github.com/openai/grade-school-math), commit `3101c7d5072418e28b9008a6636bde82a006892c`. Local `gsm8k/test.jsonl`,1,319 examples. Fields `question` and `answer`; latter includes reasoning and a `####` final answer. All records parse, have nonempty questions and final-answer delimiters. Official repository MIT license saved locally in `gsm8k/LICENSE`. Only test split downloaded; never train on it. `gsm8k_sample.json` contains three actual examples.

Use as math capability control, with a fixed answer parser. These problems may implicitly depend on2+2 and are not uniformly unrelated. Report overall accuracy and inspect changed items; do not score all counterfactual propagation as unrelated leakage.

## WikiText-2 raw v1

Source: [Salesforce/wikitext](https://huggingface.co/datasets/Salesforce/wikitext), revision `b08601e04326c79dfdd32d625aee71d232d685c3`. Local `wikitext2/{train,validation,test}.parquet`. Train36,718, validation3,760, test4,358 rows, single string field `text`. Empty lines and article headings are intentional; counts appear in `control_validation.json`. The card lists CC-BY-SA3.0 and GFDL. `wikitext2_sample.json` contains three nonblank test rows.

Train split can supply unrelated replay/preservation text; validation selects regularization/checkpoints; test is held out for NLL/KL only. Concatenate according to documented article boundaries and use identical tokenization/windows before and after editing. Drop blank rows consistently or preserve their separators; record the choice. This is a narrow text-distribution control, not proof that all unrelated behavior is preserved.

## Arithmetic isolation suite (generated locally)

Generated by `scripts/build_arithmetic_suite.py`, no model/API dependency. Local `arithmetic_isolation/{train,dev,test}.jsonl`:405/115/1,879 records (2,399 total). `arithmetic_isolation/manifest.json` records hashes/counts and counterfactual semantics; `arithmetic_sample.json` contains one example per stratum. This new dataset is necessary because entity-relation editing benchmarks lack the required arithmetic strata. It is a deterministic pilot suite, not an established validated benchmark.

Schema: `id`, `split`, `stratum`, `family`, `prompt`, `base_answer`, `edit_answer`; machine-readable `evaluation_role`, `literal_exception_should_change`, `semantic_rule_should_change`; optional operands/operator, paired AST and `pair_id`, semantic diagnostic flags. Base labels use ordinary arithmetic. The edited AST oracle recursively evaluates each operation and returns5 when the evaluated operands of a binary addition are both2; all other operations use ordinary arithmetic. This is a local operational semantics, not consistent Peano arithmetic. Ordinary labels and edited-rule labels must be reported separately.

Training contains the exact target, four paraphrases and400 replay sums. Select target/paraphrase/replay strata deliberately; do not train every condition on all405 rows. Dev uses different wording and operands21–29; replay operands30–49; test near sums0–20 and far sums50–69. Test includes15 held-out target surfaces (including three translations),440 neighboring sums,400 distant sums,882 subtraction/multiplication controls, near misses, notation variants,60 dependent ASTs with60 matched nondependent controls, four stories, six robustness diagnostics and one exact efficacy query. Dev contains15 AST pairs. Numeric templates deliberately repeat across disjoint operand domains; semantic template independence is not claimed. Small language/word-problem strata are illustrative, not powered estimates.

The literal key occurs in both training and test efficacy by design; other cross-split prompt overlap is forbidden and checked. Held-out target wording must not enter training or generated documents. `strategy_diagnostic` stories can be solved by multiplication or addition; `semantic_gold_defined=false` means no unique edit-propagation gold. Robustness diagnostics have null labels. A truth-value query mentioning2+2 is a semantic dependency, even though its surface is a lexical near miss; do not put it in the preservation denominator. Copying/counting characters in the string are preservation tasks. Non-English and Unicode cases require tokenizer-aware baseline checks.

## RippleEdits (located during official code inspection)

Source: [official repository](https://github.com/edenbiran/RippleEdits), commit `54f3b88af4895a3aacb580ec63ce7ae857185040`. Reproduce from workspace root with `uv run python scripts/download_ripple.py`; the script uses pinned raw URLs or the identical local clone. Local `ripple_edits/{popular,random,recent}.json`; full counts/hashes/schema in `ripple_validation.json`, one actual edit in `ripple_sample.json`. Counts: popular885, random1,922, recent1,948 (4,755 total;42,395,155 bytes). These are strata rather than train/test splits. Each record has the edit and six conditional evaluation criteria, with acceptable answer aliases. Retain condition queries and explicit denominators when adapting evaluation. This provides a structural-edit comparison, not an additional research direction. The repository carries MIT licensing; facts derive from Wikidata, whose source-data terms also apply. Embedded upstream data remain in the untouched code clone; the experiment-ready copy is under datasets/.
