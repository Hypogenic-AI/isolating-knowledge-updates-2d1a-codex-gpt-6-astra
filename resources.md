## Experiment handoff

The evidence-weighted ranking and rejected directions are fixed in [planning.md](planning.md): (1) preservation-constrained parametric editing; (2) exact and semantic routing boundaries; (3) training breadth versus depth of adoption. These share one frozen evaluation suite. Additional papers do not expand the implementation search space.

Start by checking model/tokenizer revisions, hardware/access and base arithmetic competence; then cache base outputs/logits. Adapt the single-edit FT loss first, include unchanged/sham/true-fact controls, and compare methods at matched efficacy using dev-selected hyperparameters. Keep exact-string routing labeled as a wrapper control. Use repeated seeds and family-aware uncertainty. Report desired semantic propagation separately from harmful preservation failures.

Primary measures: exact efficacy, paraphrase transfer, near/far/operator agreement and accuracy, paired downstream ordinary/edited-rule agreement, unrelated factual/math behavior, full-distribution KL and held-out NLL, answer5 bias, parameter change and latency. Numeric AST oracles and lexical samples are ready; broad SDF corpora are intentionally not generated in resource gathering and require a matched-token generation protocol in direction3.

## Reproducibility and limitations

Fresh .venv, pyproject.toml and uv.lock isolate resource dependencies. Run `uv sync`, followed by dataset/repository scripts documented above. No conda or ambient research environment was used. All original PDFs parse; data hashes/row counts and git exclusions are verified in notes/resource_validation.json. Model weights, covariance matrices and large synthetic-document corpora are not downloaded; full published-scale replications therefore remain outside the ready-to-run resource set. The generated benchmark is deterministic but small/templated in semantic strata. Neither zero observed leakage nor a changed probe establishes universal isolation or genuine belief.

Pipeline state is preserved in STATE.md; only the resource_finder-owned notes are updated. Completion is signaled by .resource_finder_complete after final validation.
