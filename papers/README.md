## Screening and access limitations

Paper-finder returned 233 candidates, not 233 equally relevant papers. All entries had download attempts and failures had an alternate arXiv title lookup. Broad/off-domain hits are retained as archives, not added experiment directions. Semantic Scholar rate limits and arXiv/API errors blocked many supplementary downloads. See `notes/search_downloads_retry.jsonl` for per-entry errors and `notes/search_access.csv` for reconciled local availability. Citation counts are search metadata, not independently verified. First submission years may differ from revised PDF/conference years. Missing abstracts were screened by title; no full-text review is claimed for those entries.

Reproduce: `uv sync`; `uv run python scripts/gather_papers.py`; `uv run python scripts/download_search_results.py`; `uv run python scripts/retry_search_downloads.py`. PDFs use the downloaded versions/checksums above; scripts using unversioned URLs may retrieve later revisions. All original and chunk PDFs stay in this directory; extracted notes/renderings stay under `notes/`.
