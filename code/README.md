# Official implementations

Six shallow clones, unmodified. Readmes and dependency manifests inspected; relevant entrypoint signatures checked. No training or API generation was run. Exact commits are in `notes/code_manifest.json`. Reproduce initially with `uv run python scripts/clone_repositories.py`; to reproduce the precise snapshot, fetch and checkout each manifest commit (default-branch heads can change). Keep dependencies isolated with uv; do not run upstream conda setup instructions. These are source references, not six installed working packages.

## Handoff constraints

The resource environment contains PDF/data tooling only. Runtime compatibility, CUDA availability, model license/access, tokenizer behavior, and memory must be checked before selecting model/editor. No user-specified code repository was omitted (the specification supplied papers and a dataset, not code URLs). All six repositories were discovered through official paper/blog links and therefore received source inspection rather than expensive end-to-end replication. Methods share code ancestry; treat them as correlated baselines. Preserve each upstream license and audit reuse where no root license exists. The exact-string routing control can be implemented directly without adding a framework.

The RippleEdits release resolves a paper-count inconsistency: use the actual counts in `datasets/ripple_validation.json`, not the abstract's rounded claim. This is a data provenance clarification and does not change the top-three direction ranking.
